# Les sources de l'Observatoire Business Sabaudo

> Le tableau de référence des sources **officielles et structurées**, construit selon la [doctrine](DOCTRINE_OBSERVATOIRE.md) (§ 7). Version machine : `config/sources_registry.csv` (une ligne = une fiche). Contrôle de santé : `python scripts/check_sources.py`.
>
> Constitué en octobre 2026 par 12 agents de recherche (un par territoire ou famille de sources, plus deux tours de critique de complétude), **chaque lien testé** à la main par l'agent puis re-testé par script. Doublons fusionnés, sources mortes écartées.

- **448 sources** recensées, dont **64 dans le socle** (vague 1, à brancher en premier).

- Statut : 45 déjà actives dans le pipeline, 402 à intégrer, 1 dont l'accès est à corriger.

### Légende

- **Niv.** : 1 officiel primaire · 2 intermédiaire institutionnel · 3 presse · 4 réseau / agrégateur.
- **Effort** d'intégration : faible (RSS / API ouverte) · moyen (clé, format spécifique, newsletter) · élevé (scraping, PDF).
- **Statut** : ✅ déjà dans le pipeline · ➕ à intégrer · 🔧 accès à corriger. 🛡 = le site bloque les robots (à vérifier à la main) · ⏳ = injoignable lors du test (souvent passager).
- **💡** = écosystème tech & innovation (secteur prioritaire).
